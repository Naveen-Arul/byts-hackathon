# CodeJudge AI - Frontend

This is the frontend component of the CodeJudge AI platform, an AI-powered online code judge and evaluation workspace designed to help students improve their coding skills.

## Prerequisites

- Node.js & npm/bun installed

## Setup Instructions

Follow these steps to run the frontend application locally:

```sh
# Step 1: Install dependencies
npm install

# Step 2: Start the development server
npm run dev
```

## Technologies Used

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui
- framer-motion
- Monaco Editor (for the compiler workspace)

## Building for Production

To build the static assets for deployment:

```sh
npm run build
```
