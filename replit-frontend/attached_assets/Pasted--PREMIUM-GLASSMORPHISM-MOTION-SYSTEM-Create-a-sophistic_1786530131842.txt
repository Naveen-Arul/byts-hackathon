## PREMIUM GLASSMORPHISM & MOTION SYSTEM

Create a sophisticated hybrid glassmorphism visual system for CodeJudge AI.

IMPORTANT:

Do NOT use a single-color theme.

Do NOT make the entire application dark.

Do NOT make the entire application light.

Use a carefully balanced combination of:

- Light glass surfaces
- Dark developer workspace surfaces
- White translucent cards
- Soft charcoal/slate panels
- Sky blue accents
- Emerald accents
- Cyan highlights
- Amber warnings
- Coral errors
- Very subtle violet/purple accents only where appropriate

The application should feel like a premium AI developer product rather than a generic dashboard.

==================================================
1. HYBRID LIGHT + DARK VISUAL SYSTEM
==================================================

Use different visual environments based on context.

PUBLIC LANDING PAGE:

Primarily light.

Use:

#FFFFFF
#F8FAFC
#F1F5F9

with translucent glass cards.

Use subtle ambient gradients:

Sky blue
Cyan
Emerald
Soft violet

These gradients must remain extremely subtle.

--------------------------------------------------

PUBLIC COMPILER:

Use a darker developer workspace.

The compiler/editor area can use:

#0F172A
#111827
#1E293B
#020617

However, the surrounding page should remain lighter.

This creates visual separation:

Light SaaS shell
        ↓
Dark coding workspace

The Monaco editor should use a professional dark coding theme.

Do not use an excessive neon cyberpunk aesthetic.

The compiler should feel like a premium professional IDE.

--------------------------------------------------

ADMIN DASHBOARD:

Primarily light.

Use:

White background
Frosted white cards
Slate typography
Soft blue/green accents

Allow selected analytics panels to use slightly darker glass surfaces for visual hierarchy.

--------------------------------------------------

STUDENT DASHBOARD:

Primarily light.

Use:

White
Porcelain
Very light blue
Soft emerald

Make it friendly and educational.

--------------------------------------------------

ASSESSMENT WORKSPACE:

Use a hybrid layout.

Light problem statement panel.

Dark coding editor.

Light question navigator.

Dark or semi-dark timer/status area.

This should visually separate:

"Understand the Problem"

from

"Write the Solution"

--------------------------------------------------

AI ANALYSIS SCREEN:

Use a slightly darker cinematic surface.

Background:

Deep slate / charcoal.

Use subtle glowing nodes for AI agents.

Do not use a completely black background.

Use:

#0F172A
#111827
#1E293B

with:

Sky blue
Cyan
Emerald

as agent activity indicators.

--------------------------------------------------

RESULTS PAGE:

Primarily light.

Use white glass cards with occasional dark "AI reasoning" panels.

The Master Judge section can use a premium dark glass card to visually emphasize the final verdict.

==================================================
2. GLASS CARD DESIGN
==================================================

Create premium frosted glass cards.

Use combinations of:

backdrop-filter: blur()

semi-transparent backgrounds

thin translucent borders

soft shadows

inner highlights

subtle gradients

Example visual characteristics:

background:
rgba(255,255,255,0.55)

border:
1px solid rgba(255,255,255,0.35)

backdrop blur:
18px–28px

shadow:
soft, large, low-opacity shadow

Do NOT overuse blur.

Glass should remain readable.

Cards must maintain strong text contrast.

--------------------------------------------------

DARK GLASS CARDS:

Use:

rgba(15,23,42,0.65)

with:

rgba(255,255,255,0.08)

borders.

Use subtle cyan/blue highlights.

Never make dark cards completely opaque unless necessary.

==================================================
3. GLASS LAYERS
==================================================

Create visual depth using 3 layers.

BACKGROUND

Soft gradient / ambient lighting.

↓

GLASS SURFACE

Semi-transparent frosted card.

↓

CONTENT

High-contrast text and controls.

Avoid flat UI.

Avoid excessive shadows.

Use depth through transparency and layering.

==================================================
4. AMBIENT BACKGROUND EFFECTS
==================================================

Create very subtle background lighting.

Use large blurred radial gradients.

Example:

Sky blue glow
Emerald glow
Cyan glow
Very subtle violet glow

Position them around:

Hero

AI Agent section

Compiler

Results

Do NOT create visible giant gradient circles.

The user should feel the lighting rather than immediately notice the effect.

Use:

opacity: 0.08–0.18

large blur radius.

==================================================
5. GLASS REFLECTION EFFECT
==================================================

Add extremely subtle reflective highlights to premium cards.

When the cursor moves over a card:

A soft light reflection should move slightly across the surface.

Do not create a strong glossy shine.

The effect should resemble:

premium hardware glass

rather than

gaming UI.

Use Framer Motion.

==================================================
6. CARD HOVER ANIMATIONS
==================================================

Every interactive card should have subtle motion.

Default:

transform:
translateY(0)

Hover:

translateY(-4px)

with a slightly stronger shadow.

Duration:

180–250ms.

Use:

ease-out.

Do not make cards jump.

--------------------------------------------------

For feature cards:

Hover:

translateY(-5px)

slight border illumination

very subtle background gradient

icon moves 2–3px upward

--------------------------------------------------

For agent cards:

Hover:

slight elevation

agent icon glow increases

border becomes slightly more visible

agent status indicator becomes brighter

Do NOT animate the entire card continuously.

==================================================
7. 3D TILT EFFECT
==================================================

Use extremely subtle cursor-based tilt for selected hero cards only.

Maximum:

2–4 degrees.

Apply ONLY to:

Hero AI evaluation preview

Featured Master Judge card

Important feature card

Do not apply 3D tilt to:

Tables

Forms

Code editor

Assessment questions

Navigation

This keeps the interface professional.

Do not make buttons follow the cursor aggressively.

==================================================
10. AI AGENT ANIMATION
==================================================

The 9-agent pipeline should have an intelligent visual identity.

Create a node-based animation.

Example:

                Intent
                   ↓
        ┌──────────┼──────────┐
        ↓          ↓          ↓
      Logic    Complexity   Security
        ↓          ↓          ↓
        └──────────┼──────────┘
                   ↓
              Feedback
                   ↓
             Master Judge

During analysis:

Agent nodes should softly pulse.

Connection lines should have a moving light particle.

Completed agents:

Green check indicator.

Active agent:

Cyan/sky blue pulse.

Waiting:

Muted slate.

Error:

Coral.

Do not use constant flashing.

==================================================
11. MASTER JUDGE ANIMATION
==================================================

The Master Judge should have a special visual treatment.

When evaluation completes:

1. Agent results converge toward Master Judge.

2. Master Judge card softly illuminates.

3. Score appears with a smooth count-up animation.

4. Verdict fades/slides into view.

5. Confidence indicator fills.

6. Final feedback appears.

Do not use fireworks or excessive celebration.

The animation should feel like:

"AI evaluation completed"

not:

"video game reward."

==================================================
12. SCORE ANIMATIONS
==================================================

Score circles should animate from:

0 → final score.

Duration:

800–1200ms.

Use easing.

Example:

85 / 100

The number should smoothly count upward.

Progress bars:

Animate width from 0 → final value.

Do not animate scores repeatedly.

13. PAGE TRANSITIONS
==================================================

Use Framer Motion for page transitions.

Recommended:

opacity:

0 → 1

translateY:

8px → 0

Duration:

200–350ms.

Keep transitions fast.

Do not create slow cinematic transitions between every page.

Landing page sections can reveal as the user scrolls.

Animation:

opacity:

0 → 1

translateY:

25px → 0

Use staggered children.

Example:

Feature card 2
Feature card 3
Feature card 4

appear with a slight stagger.

Do not animate every paragraph individually.

==================================================
29. DO NOT OVER-ANIMATE
==================================================

IMPORTANT DESIGN RULE:

Animation should communicate:

- State
- Hierarchy
- Interaction
- Progress

Animation should NOT exist simply because it looks cool.

Avoid:

Constant floating cards

Infinite glowing borders

Excessive particles

Large rotating objects

Aggressive 3D effects

Bouncing buttons

Screen-wide gradients

Flashing elements

Gaming-style neon effects
