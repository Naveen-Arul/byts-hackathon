# CODEJUDGE AI — COMPLETE FRONTEND APPLICATION MASTER PROMPT

Build a complete, production-quality frontend web application named **CodeJudge AI**.

CodeJudge AI is an **AI-powered coding evaluation and assessment platform** that combines:

* Online coding workspace
* AI-powered code evaluation
* Multi-agent code analysis
* Automated coding assessments
* Admin-created coding questions
* Scheduled student tests
* Role-based authentication
* Personalized AI feedback
* Master AI Judge

The frontend must be designed as a complete application, not just a landing page or compiler page.

---

# 1. CORE PRODUCT CONCEPT

CodeJudge AI has TWO separate user experiences.

## EXPERIENCE A — PUBLIC OPEN COMPILER

Anyone can access:

`/compiler`

without:

* Login
* Registration
* Authentication
* User account

A visitor can:

1. Open CodeJudge AI
2. Open the public compiler
3. Select a programming language
4. Write or paste code
5. Submit code
6. AI agents analyze the code
7. Master Judge generates an evaluation
8. User sees the complete AI feedback

This is the **Open AI Code Judge**.

---

# EXPERIENCE B — AUTHENTICATED CODING ASSESSMENT

For structured coding assessments, authentication is required.

There are two roles:

## ADMIN

Admin can:

* Login
* Create coding questions
* Edit questions
* Delete questions
* Add test cases
* Create assessments
* Assign questions to assessments
* Assign assessments to students
* Schedule tests
* Set start/end time
* Set duration
* View assigned students
* View submissions
* View AI evaluation reports
* View scores
* View assessment performance
* Monitor test status

## STUDENT

Student can:

* Register/login
* View dashboard
* View assigned assessments
* View upcoming tests
* View active tests
* Attend scheduled tests
* Open assigned coding questions
* Write code
* Run sample code if execution API exists
* Submit code
* Receive AI evaluation
* View score
* View personalized feedback
* View previous assessment results

IMPORTANT:

The public `/compiler` must remain accessible without authentication.

The assessment workflow requires authentication.

# 43. IMPORTANT ASSESSMENT VS PUBLIC COMPILER DIFFERENCE

Public compiler:

No login.

No assessment.

No assigned question.

No timer.

No student identity.

User submits arbitrary code.

AI must infer the likely problem.

Assessment:

Login required.

Question is explicitly provided.

Question comes from admin-created Question Bank.

Student is assigned the assessment.

Timer is active.

Submission belongs to the student.

AI evaluates code against the provided problem context.

This distinction must be visible in the UX.
